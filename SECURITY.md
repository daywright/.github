# Security

Please do not report security problems in public issues.

Report them privately through GitHub: open the affected repository, go to
**Security**, then **Report a vulnerability**. Only the maintainers see the report.

Daywright handles health data, so privacy bugs count as security bugs: anything
that could expose health data, photos, recordings or memory belongs here.

We aim to acknowledge a report within seven days and to agree a disclosure date
with you.
