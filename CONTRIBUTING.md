# Contributing to Daywright

Each repository has its own `CONTRIBUTING.md` with the details. These rules apply
in every Daywright repository:

1. **Sign off every commit** with `git commit -s`, under the
   [Developer Certificate of Origin](https://developercertificate.org).
2. **Inbound equals outbound.** Your change is licensed like the folder it touches,
   as mapped in that repository's `REUSE.toml`. There is no contributor license
   agreement and no copyright assignment.
3. **Talk before large work.** Open a discussion or an issue first, so we agree on
   the shape.
4. **Never commit personal data**, recordings, body photos or secrets.
5. **The [code of conduct](CODE_OF_CONDUCT.md) applies** everywhere the project
   lives.

How decisions get made is in [GOVERNANCE.md](GOVERNANCE.md).
